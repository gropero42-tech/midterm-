# Campus Facility Reservation Data Mining & Analysis

A Streamlit app converted from the submitted Google Colab notebook.

## Features
- Dashboard and dataset summaries
- Raw and cleaned dataset preview with CSV download
- Data cleaning summary
- Exploratory visualizations
- Decision Tree reservation non-completion risk prediction
- Model evaluation metrics and feature importance

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Notes
The notebook generates synthetic reservation data, so the app does the same. Predictions are demonstrations based on this synthetic dataset, not validated predictions for real campus reservations.
